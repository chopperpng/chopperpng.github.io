PANKU!

UNREAL ENGINE 5 / BLUEPRINTS
↗
SOLO PROJECT · FIRST UNREAL ENGINE PROJECT

A five-level Doom-like boomer shooter built entirely in Unreal Engine 5. The player fights through levels, finds weapons and keys, opens locked areas and reaches the end of each stage.

I built the entire project using Unreal Blueprints, including the weapon systems, enemy systems, controller support, animation systems and visual effects. I also created the game's audio and handled the overall game design.

UE5 BLUEPRINTS GAME DESIGN AUDIO VFX CONTROLLER SUPPORT
02

CLEAVER VALLEY

UNITY / C++
SOLO PROJECT · UNIVERSITY PROGRAMMING PROJECT

A simple arena-based shooter created in Unity using C++. The player starts with four weapons, switches between them and fights waves of randomly spawning enemies.

The entire game and all of its programming were created by me. The project focused heavily on applying C++ programming concepts to a playable game.

UNITY C++ GAMEPLAY PROGRAMMING WEAPONS
03

CLOCK FARM

UE5 / GAME JAM
3-DAY GAME JAM · LAME JAM · TEAM OF TWO

A farming game created in three days for Lame Jam. The player must grow crops and earn enough money to pay off their debt.

The game's main mechanic is that growing plants costs the player years of their life. I handled a large amount of the Blueprint programming, all of the game's art and all of its audio.
